# Earlier work (up to 2025-09-28)

## Summary

Catch-up entry for the revamp work done before the changelog existed. The items below were
finished, but weren't recorded with dates. Git history has the details.

## What changed for players

- Prestige mechanics.
- Sammy powerups.
- Less honeycomb collected when the bee dies.
- Bonus honeycomb for meeting a level's success criteria.
- Fixed the distance calculation.
- Touching Sammy no longer adds to max health, which used to make the current health percentage drop.
- Sammy time no longer seems to slow the stingers.
- The shop menu was reworked, and the first cosmetic purchases were added.
